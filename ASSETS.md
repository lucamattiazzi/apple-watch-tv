# Animation assets

The included animation content is original procedural artwork by Luca Mattiazzi,
dedicated to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
This preserves the existing dedication for Orbita and the included screensavers.

- `scripts/generate_default_video.py` generates the original monochrome Orbita
  animation and its legacy frame fonts. See [the original asset notes](out/default/README.md).
- `scripts/generate_included_videos.py` and `scripts/screensaver_art.py` generate
  the current Castaway, Orbita, Aquarium, Gears and 3D Maze frames in monochrome
  and colour. The ten `.video` files are included in `WatchTV/Shared/IncludedVideos/`.
- `docs/media/orbita.gif` previews the included Orbita animation.

These animations contain no external footage, photographs, music, sprites or
Seiko promotional material. Castaway and the maze reference the idea of old
screensavers; their artwork is original, not extracted from those products.

The CC0 dedication covers animation content. The project's code is MIT-licensed;
tools and dependencies keep their respective licenses.
